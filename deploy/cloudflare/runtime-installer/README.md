# Runtime Installer Worker

This Worker serves the public runtime installer entrypoints for Vilano Runtime:

- `https://runtime.vilano.ai/install.sh`
- `https://runtime.vilano.ai/release.json`

It is intentionally thin:

- `install.sh` and `release.json` are generated by the runtime release pipeline
- large runtime tarballs stay on GitHub Releases
- the Worker only serves the install/update front door

## Local Flow

Generate release assets, then sync them into the Worker public directory:

```bash
bun run build:release
bun run sync:installer-worker
```

## Deployment

The release workflow publishes the GitHub release first, then deploys this Worker so the served
`release.json` points at live release assets.

Cloudflare secrets expected by the workflow:

- `CLOUDFLARE_API_TOKEN`
- `CLOUDFLARE_ACCOUNT_ID`

The runtime route itself (`runtime.vilano.ai/*`) should be attached in Cloudflare for the deployed
Worker.
