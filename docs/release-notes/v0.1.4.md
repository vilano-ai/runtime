## Summary

- release type: `0.x patch release`
- runtime version: `0.1.4`
- release date: 2026-04-29

Vilano Runtime `0.1.4` is a patch release focused on macOS launch-gate reliability under
local SQLite contention.

## Compatibility

- protocol version: `1`
- schema version: `13`
- support scope: local-first, single-machine, Bun-first

## Highlights

- Public project reads now use the runtime's SQLite busy-retry path, covering CLI workflow
  resolution during bursty run starts.
- Run read models now retry transient SQLite connection-pool pressure, including DBConnection
  queue drops seen on macOS CI.
- SQLite busy detection now recognizes connection-pool queue-pressure messages in addition to
  database lock and busy messages.

## Upgrade

```bash
vilano update
vilano version
```
