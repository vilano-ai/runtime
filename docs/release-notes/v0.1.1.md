## Summary

- release type: `0.x patch release`
- runtime version: `0.1.1`
- release date: 2026-03-17

Vilano Runtime `0.1.1` is a patch release focused on two concrete issues discovered immediately
after the `0.1.0` launch: slow activation staging on large projects and sealed snapshot cleanup on
macOS.

## Compatibility

- protocol version: `1`
- schema version: `13`
- support scope: local-first, single-machine, Bun-first

## Fixes

- Activations now import workflow and service definitions directly from the pinned project
  snapshot instead of copying the full snapshot into a separate import-cache layer on every turn.
  This removes the multi-second warm-path floor caused by repeatedly restaging large dependency
  trees.
- Writable per-activation workspaces still exist, but they now share `node_modules` directly from
  the pinned snapshot.
- Project snapshot pruning now reopens sealed snapshot directories before deleting them, which
  prevents `EACCES` failures during `vilano project add` and `vilano project sync` on macOS.
- Registration validation cleanup now uses the same sealed-snapshot removal path, so failed
  registrations do not leave behind undeletable snapshots that poison later project lifecycle
  commands.

## Upgrade

vilano update
