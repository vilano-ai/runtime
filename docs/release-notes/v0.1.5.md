## Summary

- release type: `0.x patch release`
- runtime version: `0.1.5`
- release date: 2026-05-26

Vilano Runtime `0.1.5` is a patch release focused on bounded local storage,
replay reliability, and SQLite contention hardening.

## Compatibility

- protocol version: `2`
- schema version: `15`
- support scope: local-first, single-machine, Bun-first

## Highlights

- Large replay event bodies are externalized to runtime-managed payload files and
  resolved transparently for inspect and replay.
- Runtime storage is easier to operate with storage usage views, `vilano daemon prune`,
  configurable snapshot hygiene, orphan payload cleanup, and capped exec capture
  persistence.
- Large replay payloads for run starts, failures, cancellations, service turns,
  retries, supervision, and admin stop/cancel flows are published before SQLite
  write transactions.
- SQLite contention handling now uses configurable busy timeouts, immediate write
  transactions, busy retries for public reads, and contention coverage for
  concurrent run starts and service traffic.
