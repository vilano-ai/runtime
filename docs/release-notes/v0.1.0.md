## Summary

- release type: `0.x preview`
- runtime version: `0.1.0`
- release date: 2026-03-10

Vilano Runtime `0.1.0` is the first public OSS release of a local-first BEAM-backed agent runtime.
The kernel owns durable coordination, recovery, supervision, and messaging semantics, while
JavaScript/TypeScript workers stay disposable and replay-driven.

## Support Matrix

- supported operating systems:
  - macOS Apple Silicon (`darwin-arm64`)
  - Linux x86_64 (`linux-x64`)
- supported worker runtimes:
  - Bun worker
- preview worker runtimes:
  - Node worker

## Compatibility

- protocol version: `1`
- manifest version: explicit `vilano.manifest.json` is the recommended path for OSS `0.1`
- schema version: `9`
- upgrade notes:
  - installer and `vilano update` both default to the stable channel
  - preview installs remain opt-in through `VILANO_RELEASE_CHANNEL=preview`
  - packaged installs use the managed launcher at `~/.vilano/bin/vilano`
  - packaged Bun worker startup is self-contained; packaged Node worker startup remains preview-only

## Highlights

- The runtime now presents a clearer BEAM-backed agent-kernel story instead of a generic local job
  runner story.
- Workflows and services now expose agent-runtime primitives such as `monitor`, `link`,
  `trapExit`, workflow supervision groups, mailbox inspection, overload rejection, passivation,
  discovery, and durable pubsub.
- Stable-channel install and update behavior now match across `install.sh` and `vilano update`.
- Packaged installs verify extracted payload contents before activation and print explicit launcher and
  `PATH` guidance after install.
- Distribution docs now align with the actual managed install layout, runtime home behavior, and
  manifest posture.
- The repo now includes a canonical multi-agent reference example and a first-run walkthrough.
- `vilano init` is documented as a generated starting point rather than a guarantee that every
  exported definition is correct.

## Known Limitations

- local-first single-machine runtime
- same-user trust model; no sandboxing in `0.1`
- Node worker remains preview
- Windows is not part of the supported matrix
- hosted/cloud mode is not part of `0.1`

## Install

```bash
curl -fsSL https://runtime.vilano.ai/install.sh | bash
~/.vilano/bin/vilano version
~/.vilano/bin/vilano doctor
~/.vilano/bin/vilano update --check
```
