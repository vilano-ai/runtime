## Summary

- release type: `0.x OSS release`
- runtime version: `0.1.0`
- release date: 2026-03-10

Vilano Runtime `0.1.0` is the first public OSS release of a durable runtime for building agent
systems. The current OSS release path is local-first and single-machine. The kernel owns durable
coordination, recovery, supervision, and messaging semantics, while JavaScript/TypeScript workers
stay disposable and replay-driven.

## Support Matrix

- supported operating systems:
  - macOS Apple Silicon (`darwin-arm64`)
  - Linux x86_64 (`linux-x64`)
- supported worker runtimes:
  - Bun worker

## Compatibility

- protocol version: `1`
- manifest version: explicit `vilano.manifest.json` is the recommended path for OSS `0.1`
- schema version: `13`
- operator notes:
  - installer and `vilano update` both default to the stable channel
  - alternate release channels can be selected with `VILANO_RELEASE_CHANNEL`
  - packaged installs use the managed launcher at `~/.vilano/bin/vilano`
  - packaged Bun worker startup is self-contained

## Highlights

- The runtime presents a clear BEAM-backed agent-kernel story instead of a generic local job
  runner story.
- Workflows and services expose agent-runtime primitives such as `monitor`, `link`,
  `trapExit`, workflow supervision groups, mailbox inspection, overload rejection, passivation,
  discovery, and durable pubsub.
- Stable-channel install and update behavior match across `install.sh` and `vilano update`.
- Packaged installs verify extracted payload contents before activation and print explicit launcher
  and `PATH` guidance after install.
- Distribution docs align with the managed install layout, runtime home behavior, and manifest
  posture.
- The repo includes a runnable starter path, a repo-checkout demo, and smaller focused examples.
- `vilano init --starter` scaffolds a runnable project, while plain `vilano init` remains the
  generated manifest path for existing codebases.

## Install

```bash
curl -fsSL https://runtime.vilano.ai/install.sh | bash
~/.vilano/bin/vilano version
~/.vilano/bin/vilano doctor
~/.vilano/bin/vilano update --check
```
